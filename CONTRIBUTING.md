# Contributing

Use a dedicated branch, explain the customer promise being protected, and include a regression test that fails before your fix. Run the README checks. Keep fixture failures intentional and documented. Do not loosen policy to make a repair pass.

All contributions are MIT licensed. Sign off commits with `git commit -s` to certify the Developer Certificate of Origin 1.1: https://developercertificate.org/.

For this hackathon submission, freeze the submitted repository and materials after October 27, 2026 at 13:00 UTC. Continue later work in a separate fork until judging finishes and changes are permitted.
