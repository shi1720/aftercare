Aftercare closes that recovery loop.

The bounded reference controller creates a repair, runs the contracts, checks executable capabilities, and packages the exact tested source. Real loopback requests validate the candidate before sandbox promotion. An independent postcheck verifies the active revision.

Every stage leaves evidence: the source diff, test results, ledger, artifact hashes and a linked decision record. Hashes detect changes relative to a trusted head; they are not an external signature.

Here is the separate GitLab Duo flow. Its investigation agent reproduces the defect. Its repair agent independently changes the source and adds regression tests. The pipeline protects the existing contract and limits changed paths. GitLab keeps the source change, tests and passing pipeline together for human review.

The browser sandbox is deterministic, with zero model calls. The connected GitLab workflow uses AI and is supervised. Each view shows what actually ran.

Finally, this unsafe candidate asks for forbidden capabilities. Aftercare blocks it before execution and confirms the safe revision remains active.

Aftercare is built for SaaS engineering teams handling transaction incidents on GitLab.

Keep the customer promise, and bring the proof.
